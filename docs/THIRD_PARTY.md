# Provider image provenance

Only Google Cloud identification assets are included in this repository. The Android file `apps/android/app/src/main/res/drawable/google_cloud.png` is an identical local copy of the [Google Cloud logo](https://www.gstatic.com/cgc/renaissance/image/MultiPath_Bottom_2X_Centered_static.png), sourced via the [official icon page](https://cloud.google.com/icons) during the original work on 2026-10-10. They identify the provider; they do not imply endorsement or a connected account. Runtime does not fetch external logo images.

Dependency integrity/version/license metadata is in docs/provenance/source-manifest.json; package license files remain with installed dependencies. The Gradle wrapper originates from Gradle and retains its source notices and distribution digest. This inventory does not grant redistribution rights. No new project license has been selected as part of migration.
